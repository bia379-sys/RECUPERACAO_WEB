Fundamentos de Desenvolvimento Web

Hardware x Software

O hardware é a parte física de um aparelho, ou seja, tudo o que você pode tocar, como a tela, o processador, os circuitos, o teclado e o mouse. Já o software é a parte lógica, composta pelos programas, aplicativos, sistemas operacionais e códigos que fazem essas peças físicas funcionarem. Eles são totalmente dependentes: o hardware serve como o corpo da máquina e o software funciona como a mente, de modo que um computador ou celular precisa de ambos para ter utilidade.

Internet x Web

A Internet é a infraestrutura física global feita de cabos, satélites e computadores conectados que transportam dados pelo mundo. A Web é um serviço virtual que roda dentro dessa rede, sendo o sistema de páginas e sites que acessamos pelo navegador. Basicamente, a Internet é a grande estrada mundial e a Web é apenas um dos carros que trafegam por ela, dividindo o espaço com e-mails, jogos e aplicativos de mensagens.

Cliente, Servidor, IP, DNS, Domínio e Hospedagem

O cliente é o seu aparelho que pede para ver um site, enquanto o servidor é o computador que guarda os arquivos dele. O IP é o endereço numérico de cada máquina e o domínio é o nome textual do site (ex: site.com) criado para facilitar a memorização. O DNS funciona como uma lista de contatos que traduz esse nome textual no IP numérico correto para achar o servidor. Por fim, a hospedagem é o espaço alugado dentro do servidor onde o site fica armazenado para ficar disponível na internet.

HTTP, CSS e JavaScript

O HTTP é o protocolo de transporte que dita as regras para enviar e receber os arquivos de um site entre o servidor e o cliente. Quando esses arquivos chegam, o HTML cria a estrutura e o conteúdo bruto da página, como os textos e botões. O CSS cuida da estilização, aplicando cores, fontes, alinhamentos e todo o design visual sobre essa estrutura. Por fim, o JavaScript adiciona interatividade e comportamento, criando funções dinâmicas como pop-ups, animações e cálculos em tempo real.

Sequência Histórica

1. 1969: Criação da ARPANET, a primeira rede de computadores interconectados.

2. 1989: Proposta da World Wide Web por Tim Berners-Lee.

3. 1991: Lançamento do primeiro site e do primeiro navegador web.

4. 1993: Popularização da Web com o lançamento do navegador Mosaic.

5. 1995: Surgimento do JavaScript e do CSS, permitindo interatividade e estilização.

6. 2004: Início da era das redes sociais com o lançamento do Facebook.

7. 2007: Lançamento do iPhone, popularizando o acesso à web em dispositivos móveis.

8. 2010: Crescimento do HTML5 e CSS3, trazendo novos recursos para a web.

9. 2015: Adoção generalizada de frameworks JavaScript como Angular e React.

10. 2020: Expansão da web progressiva (PWA) e maior foco em acessibilidade e desempenho.
