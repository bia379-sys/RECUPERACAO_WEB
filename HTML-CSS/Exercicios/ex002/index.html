O que aprendi até aqui?👍

Nas aulas iniciais, o aprendizado começou pela informática básica, diferenciando hardware (componentes físicos como processador, memória RAM e armazenamento) de software (sistemas operacionais, navegadores e editores de código).
Em seguida, compreendeu-se a evolução histórica da Internet, desde a criação da ARPANET e a adoção do protocolo TCP/IP até a tecnologia de comunicação dividida em pacotes de dados. Nesse contexto, estabeleceu-se a distinção essencial entre a Internet — que é a infraestrutura física de rede que conecta dispositivos — e a Web, que é o serviço de páginas e recursos acessados por meio dos navegadores.

O conteúdo avançou para o funcionamento da rede e o ciclo conhecido como o caminho de uma página, estruturado no modelo cliente-servidor, no qual o cliente (navegador) faz uma requisição e o servidor fornece a resposta. Esse processo envolve equipamentos como modem e roteador, o uso de endereços IP para identificar dispositivos na rede e o sistema DNS, que traduz endereços IP numéricos em nomes amigáveis para o usuário. Também foi definida a diferença entre domínio (o nome do site) e hospedagem (o servidor onde os arquivos ficam armazenados), além dos protocolos de transferência HTTP e HTTPS (este último com camada de criptografia).

Por fim, estudou-se o papel das três tecnologias fundamentais da Web: HTML para estruturar e marcar o conteúdo, CSS para a apresentação visual e JavaScript para a interatividade. Foram praticados conceitos práticos como a anatomia de tags e atributos no HTML, os seletores, propriedades e valores no CSS e a montagem da estrutura básica de um arquivo web com doctype, head e body, como < p > e < br > que estruturam o conteúdo™. Na parte prática, aprendeu-se a configurar o editor de código Visual Studio Code, organizar as pastas do projeto, criar arquivos .html e executar o ciclo de desenvolvimento testando e inspecionando a página diretamente no navegador.
