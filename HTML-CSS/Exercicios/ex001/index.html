O que revisei

A Internet é uma rede global de computadores interconectados que permite o compartilhamento de informações, dados e serviços em todo o mundo.

O HTML (Hypertext Markup Language) é a linguagem de marcação padrão usada para criar páginas da web. Ele define a estrutura e o conteúdo das páginas, permitindo que os navegadores exibam corretamente o texto, imagens, links e outros elementos.

O CSS (Cascading Style Sheets) é uma linguagem de estilo usada para definir a aparência visual das páginas da web. Ele permite controlar cores, fontes, layouts e outros aspectos de design, separando a apresentação do conteúdo.
